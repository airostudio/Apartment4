Stripe Settings

Stripe API keys are managed via Vercel environment variables

API keys are set as Vercel environment variables — they never appear in the browser or source code. Add STRIPE_PUBLISHABLE_KEY and STRIPE_SECRET_KEY in your Vercel project under Settings → Environment Variables. Use live keys (pk_live_ / sk_live_) for real payments, or test keys (pk_test_ / sk_test_) while developing.

How to update keys:
